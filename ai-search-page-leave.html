API 参考
更新时间：2026-09-24 09:52ArkTS API

terminateSelf

Phone 12+ | PC/2in1 13+ | Tablet 12+ | TV 19+ | Wearable 18+
terminateSelf(callback: AsyncCallback<void>): void

销毁 UIAbility 自身，通过 callback 接收异步结果。此接口需在主线程调用。

i 说明

调用该接口后，任务中心默认仍保留该任务。如需同时清理任务，请将 配置为 true。

元服务API：从 API version 11 开始支持在元服务中使用。
系统能力：SystemCapability.Ability.AbilityRuntime.Core

参数

参数名类型必填说明
callbackAsyncCallback<void>是异步回调。销毁成功时 err.code 为 0，否则返回对应错误信息。

错误码

错误码的含义可参阅通用错误码与元能力子系统错误码说明。

错误码ID错误信息
401参数校验失败。
16000011上下文不存在。
16000050内部错误。

示例

调用接口结束当前 UIAbility，并在回调中处理执行结果。

this.context.terminateSelf((err) => {
  if (err.code) {
    console.error(err.message);
    return;
  }
  console.info('UIAbility 已销毁');
});

控制销毁后是否移除最近任务

terminateSelf() 负责销毁当前 UIAbility。removeMissionAfterTerminate 则决定销毁后，是否将对应任务从最近任务列表中移除。

false默认值销毁后保留任务
true销毁后移除任务

如果希望退出后不再保留任务快照，在 module.json5 → module → abilities 中，为对应的 UIAbility 设置：

module.json5 · 配置片段
{
  "name": "EntryAbility",
  "removeMissionAfterTerminate": true
}
设备差异 · 在 2in1 设备和平板设备的自由多窗模式下，此配置不生效，默认移除任务。
